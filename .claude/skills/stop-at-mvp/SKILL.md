name: stop-at-mvp
description: Force an MVP-first scope and defer non-essential enhancements.
user-invocable: false
---

Apply MVP scope control:
1. Define must-have deliverable
2. Defer nice-to-have additions
3. Keep implementation minimal and reviewable
4. Propose a clear phase-2 backlog

If scope expands, explicitly warn and refocus.
