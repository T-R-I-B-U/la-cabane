---
name: naming-check
description: Validate naming conventions for components, functions, files, and constants.
---

Run naming checks for touched code.

Conventions to enforce:
1. Components in PascalCase
2. Functions and vars in camelCase
3. Constants in UPPER_SNAKE_CASE only when true constants
4. Descriptive filenames matching entity/module role

Report only naming issues with direct rename suggestions.
